# iza-filters

Path of Exile 1 loot filters, with custom sounds bundled.

| Filter | Download |
|---|---|
| DuelistA5 | [DuelistA5.zip](../../releases/latest/download/DuelistA5.zip) |
| ShadowBladetrap | [ShadowBladetrap.zip](../../releases/latest/download/ShadowBladetrap.zip) |

## Install

1. Extract the zip straight into `Documents\My Games\Path of Exile`
   (so the `.filter` file and the `poeft-sounds-v2` folder sit directly in it).
2. In game: **Options > Game > Item Filter**, pick the filter and hit reload.
