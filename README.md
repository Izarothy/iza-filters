# iza-filters

Path of Exile 1 loot filters, with custom sounds bundled.

## DuelistA5

**Download:** [DuelistA5.zip](../../releases/latest/download/DuelistA5.zip)

1. Extract the zip straight into `Documents\My Games\Path of Exile`
   (so `DuelistA5.filter` and the `poeft-sounds-v2` folder sit directly in it).
2. In game: **Options > Game > Item Filter**, pick **DuelistA5** and hit reload.
